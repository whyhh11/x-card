# x-card

可离线使用的 X 风格帖子卡片生成器。直接用浏览器打开 `index.html`，无需安装或构建。

- 点卡片上的文字修改名字、用户名、发布时间、正文和互动数字。
- 互动数据支持手动编辑和随时间随机，提供日常、热门、爆款三档热度。
- 同一组随机数据按发布时长线性增长，修改时间后离开输入框即可更新；点击「随机一组」重新生成速率。评论、转发、点赞和浏览量相互关联，数字取整后显示。
- 时间支持刚刚、秒、分钟、小时、天、周及 `YYYY-MM-DD` / `YYYY-MM-DD HH:mm`。日期按当前设备的本地时间计算；无法识别的时间和未来日期保留原数值并提示。
- 最多四条帖子，可更换共享头像、切换蓝标、给末条添加或移除配图、删除末条。
- 当前浏览器自动保存草稿。大图片可能超出浏览器存储空间，此时会提示。清除浏览器数据会移除草稿。
- 导出 PNG 宽度 1206px，支持下载及手机长按保存。

互动数字为模拟数据，不连接 X。PNG 导出不含编辑控件。

## 验证

使用 Node.js 安装 Playwright 开发依赖及 Chromium 后运行：

```sh
npm install --no-save playwright
npx playwright install chromium
node tests/smoke.cjs
```

测试覆盖时间解析、增长比例、编辑保留、模式切换、草稿恢复、PNG 导出、320–1440px 排版与重置。

可选环境变量：`PLAYWRIGHT_MODULE` 指定 Playwright 模块路径，`CHROME_PATH` 指定测试浏览器路径，`SCREENSHOT_PATH` 保存测试预览与导出图。
